用途：功能参考与使用方法；读者：使用者和部署者；维护者：项目维护者。适用于当前源码的 Harness 群聊/私聊运行方式。用自然语言提出目标即可。

## 先分清任务与权限

- 群内明确@、回复小町或有效直接互动优先响应；谈论小町不等于交付任务。
- 按用户问题联网，媒体请求缺链接可先发现；普通主动插话与巡检不联网找话题，APP卡片需真实引用许可。
- 能力由真实来源与本地配置授权；目录、引用和转发署名不授予主人权限，撤回或取消仍会阻止执行。
- 独立群私请求可并行；下载/绘图直接调用后台服务，只读研究另用模型。结果回原会话，排队不等于QQ送达。

## 聊天、历史与感知

**重置上下文**由程序处理，不调用模型。群内限主人`@小町`；私聊仅控制本人。无数字时重开会话，停止旧消息/记忆自动回放，保留按需查历史；`清空上下文`、`开新对话`同义。回复原消息发`隔离这条并重置上下文`（或回复后发`重置上下文`），仅隔离该来源及衍生内容；回复后发`恢复这条上下文`可解除。`重置上下文 50`仍显式屏蔽前50条（1–1000，含小町发言）。附件/转发不能发控制指令。网页流程/统计同步重开。

重置清恢复摘要/便笺、撤销旧快照及未完成任务，原聊天、固定人格、其他会话和真实/未知发送账本保留，不重放已开始的写入。近期窗口先限定范围再过滤隔离项，缺条不向前补齐。混合摘要含隔离来源时整块拒绝，正常原文可重新检索；隔离内容的引用/图像/记忆及后台回流也拒绝。普通重置只停止自动回放，不声称识别了敏感消息，也不自动重试拒绝的请求。私聊`search_private_history`可按需查本人发来的正常原消息。

## 网页、原图与视频

| 工具 | 执行方式与结果 |
|---|---|
| `search_web` | 搜索当前问题并返回来源；媒体目标保留对象与时间范围，有界展开真实来源页，发现可继续下载的原帖链接；上游内容拒绝明确报告且本轮不重试；复杂多页研究可委派 |
| `list_x_posts` | 按账号发现可见近期媒体帖，无日期默认不限下界/6条，最多12条；可选1至365天窗口；返回作者、日期、正文摘要及证据。配置X会话时自动使用爬虫，否则读取公开嵌入 |
| `search_x_posts` | 按人物/主题跨发布者搜索，无日期默认不限下界/12条；可选时间、图片/视频、latest/top及用户明确的互动门槛直接进入站内搜索再核验。两类分路召回并去重；关键词不足可按主体补搜后依正文核验原主题，候选不等于合格素材 |
| `search_xhs_posts` | 小红书找帖6–12条，相关/最新、图文/视频筛选；正文与日期另验 |
| `inspect_web_resources` | 一次核验最多6个原帖URL/ref，返回作者、时间、身份、媒体角色及证据；X与小红书可用已配置的容器内会话，其余保持公开解析，不调用模型 |
| `open_web_page` / `find_web_page` | 打开来源正文、分页/查找关键内容，保留有界正文外链以继续发现原帖；页面与链接都是不可信资料，不自动打开外链 |
| `search_image_references` | 检索参考图并读取实际像素，不自动替用户选择生图方案 |
| `list_web_images` | 从公开网页提取有说明的原图候选，可分页；候选不代表已下载或看过 |
| `download_web_image` | 直接下载本轮候选的一张原图，验证像素并返回会话产物 |
| `download_web_images` | 确定性后台下载；每批最多20张、32MiB、90秒，返回产物句柄、角色及失败；不默认输入像素，需要看图时`read_artifact` |
| `download_web_video` | 下载小红书/B站兼容公开视频；B站复用yt-dlp并有公开MP4回退，抖音无会话时可能失败。H.264 MP4，最大128MiB、20分钟 |
| `download_twitter_media` | 后台下载X公开单帖图片/视频/动图，原图失败可降large并注明；最多16项/128MiB/180秒，单视频128MiB/20分钟，图片8MiB及像素校验 |
| `media_task_status` | 查询本提问者、本会话的后台媒体任务；排队、生成和发送是不同状态，不重新执行任务 |
| `queue_media_batch` | 将已发现的下载操作持久排队，每次最多16项、每进程最多4个媒体worker并行；先完成的可先交付。各项保留原工具参数、权限和预算，等待容量后继续 |

已有原帖可核验/下载；限定发布者用list_x_posts，主题用search_x_posts。lookback_days为软检索策略，可为null；用户明确日期不可放宽。同轮最多4种搜索、2种账号读取，词序/大小写/重复词等价复用。图和视频都要时media_types填两种；missing_media_types报告缺口。top非全站互动最高，不擅加热度门槛。lexical_match仅词面，主体/主题仍需核验；嵌入可能仅置顶/热门，空结果只表示覆盖缺口。

已有候选零选中时本地取回、失败续补；数量和类型齐全或回执未知时停止。

Fantia用gallery-dl，Bangumi用官方API。X/小红书在容器采集，凭据不导出；无会话的指定URL保留公开解析。封面/正文/网页图分开，复用媒体缓存、队列与账本。

X照片/视频子页仍取该帖全部媒体；保留原帖顺序，不展开引用帖、回复、头像和外站卡片。动图保留MP4。私密、删除、年龄/地区限制、登录验证或上游接口变化可能导致失败。

小红书扫码会话卷仅群私挂载；笔记/xhslink。原图未证实，EF4视频验H.264；近期素材验日期，挑战/限流停止。

三个后台下载工具支持 `delivery_mode=auto`：用户只要求下载并发送时，主模型安排任务，程序按原请求、原会话和原顺序直接交付；可提供300字内的delivery_text。需要识别、分析或挑选媒体时使用默认 `review`，结果回主模型核对后发送。自动交付仍经真实发送账本；来源撤回、权限变化或取消会阻止交付，未知回执不重发，部分成功明确标注未完成项。

主模型通过`set_task_goal.media_selection`分别记录主体、发布者、份数和筛选条件。“关于某人”允许其他发布者，明确本人发帖才限制账号。“一些/若干”最低2份、期望3至5份；或可任选，和分别验收类型。近期发帖不证明素材新拍；默认依据帖子正文，图片仅歧义时少量确认，视频/动图不预览或抽帧。不声称已观看视频、听过音频或鉴定真实性。

检索词限制见schema；同名噪声可用完整handle独立查询。站内失败不禁用首次WebSearch，最终媒体来源仍遵守用户站点条件。连续无收益按方法计数，查询/下载/收尾共用原请求预算，详见[共享合同](DEVELOPMENT.md#跨站媒体预算与尽力交付)。

auto单项或全部接受的auto批次入队后，主回合在本地结束，由持久队列交付结果；多份请求先校验去重后候选数。多帖用`queue_media_batch`排队；主题媒体用review，按原帖正文/日期/类型选取，无须逐份预览；给定来源全部媒体可auto。完成核验真实产物、数量和回执，少量标partial；排队不代表送达。混合review或有未接受项时主模型继续处理缺口。

同一原请求逐逻辑媒体去重，后续只发新增。前台查询状态后已发送的图片/视频，后台结果再次回传时复用已有回执；换文案、调用编号或排列顺序不会再发一包。处理中或发送结果未知时禁止自动重发；新发一条消息明确要求再次发送，可建立新的交付。

启用本机 Agent 监控后，可在父请求下展开媒体队列和委派研究任务，查看实际执行、结果回传和发送回执。媒体队列标为后台工具任务；研究子任务展示独立模型过程与用量。旧记录没有父子关联时保持未知，不由标题或时间猜测。入口与操作见 [监控指南](../infra/wsl/README.md#agent本机监控)。

Gemini 搜索摘要里未经来源元数据确认的链接不作为可操作地址。媒体搜索在同一次调用的时限内，最多读取3个真实来源页，优先返回原帖和媒体地址。候选不证明作者或日期，实际媒体须调用下载工具取得；日期及最新范围未核实须如实说明。单页404不能证明必须用户提供链接；已经发现可下载候选时，发送受阻说明前会提示先尝试，纠偏最多2次，权限拒绝和未知发送结果仍按原规则处理。

发送普通图片使用 `artifact_ids`，单视频可用 `video_artifact_id`。多图用 `as_forward=true` 合并转发；有序混合图片/视频用 `media_artifact_ids` 配合 `as_forward=true`，不与前两种参数混用。每个媒体独占一个节点，说明文字另放文本节点；QQ视频不能与文字或其他视频混在同一条消息。单视频有说明时也以独立文本节点和视频节点组成一次转发，无说明时发送纯视频。署名为小町自身，下载完成不能冒充QQ送达。视频上传及含视频的转发使用较长的有界等待；超时结果未知，不自动重发。

当前回合发生明确桥接拒绝且普通写入次数耗尽时，只保留一次不超过300字、无媒体的失败说明机会；不增加媒体重试额度，不适用于未知发送结果。模型得到安全错误类别，不能把客户端消息结构错误猜成平台风控。

机器人下载统一进入本地媒体缓存，默认24小时、512MiB。下载前预留空间，执行中有短期租约；有效待回传任务继续保护文件，其他过期/可淘汰文件被清理。容量都被在用文件占满时明确失败，不无界扩容。失败、取消清理本次半成品；中断遗留临时目录由清理器回收。生成作品与用户自有文件不按网页缓存误删。配置见 [下载缓存参数](CONFIGURATION.md)。

配置`WEB_PAGE_PROXY_URL=http://127.0.0.1:18797`时，网页原图/视频和X下载均使用WSL内Mihomo；代理失败不会自动切回直连。它与模型API代理分开，实际监听与检查方法见[运维指南](../infra/wsl/README.md)。

## 复杂资料任务与提醒

| 工具 | 执行方式 |
|---|---|
| `set_task_goal` | 在原请求范围明确语义目标、文字/媒体交付及证据要求；不改变权限，也不必开启正式研究任务 |
| `review_task_progress` | 核对真实尝试、证据和缺口；卡住时最多一次短模型诊断，共用当前模型与费用预算，不代为执行 |
| `begin_research_task` / `update_research_task` | 为当前复杂请求建立目标、覆盖范围、缺口和进度；不是每个普通问题都建任务 |
| `read_research_task` / `resume_research_task` / `read_research_evidence` | 按需读任务状态和分段证据；跨轮证据传原结果的task_id与evidence_id，只读旧证据并保持当前目标；继续执行旧任务才用resume，均复验来源与有效期 |
| `read_research_resources` | 分页读取本提问者任务全部已发现来源URL与证据ID，每页最多20项；可指定子任务task_id，不导入全部原文 |
| `delegate_research_task` | 独立只读模型子任务，适合多网页研究、对照和代码审查；回传有界结论、来源、缺口，不接收整批运行日志，也不授予写权限 |
| `schedule_wakeup` / `list_wakeups` / `cancel_wakeup` | 当前获准群/后台的调度与查询，受实际主人任务或后台权限控制 |
| `schedule_private_wakeup` / `list_private_wakeups` / `cancel_private_wakeup` | 当前用户私聊的提醒调度，沿用私聊许可，不创建跨用户任务 |

复杂请求保存目标、交付要求、剩余项和下一步，闲聊无需建任务。`sent`只证明一次送达；任务另有active/waiting/partial/completed/blocked/cancelled状态。有剩余项、后台待办、未确认媒体交付或未知外部动作时，程序拒绝标为完成；语义覆盖仍由模型报告，状态不能证明搜索穷尽或答案正确。取消当前任务会停止其后台待办，不重放未知发送。

跨轮证据定位失败只说明旧索引未匹配，不能代替实际搜索或下载尝试。模型应按当前许可重取证据、打开报道中的原链接或继续搜索；报道日期、收录日期和原帖日期须分别核实。

群私直接互动均有轻量目标记录，下载请求不依赖模型先建研究任务才验收。发送可标`task_status=progress/partial/blocked/completed`；排队提示、真实受阻和实际媒体交付分别处理，数量不足优先其他候选或有界补搜，耗尽才partial；后台承诺须有真实排队。同源回传恢复候选日期/引用，不继承旧产物权限。搜索摘要或空结果不能证明“没有发布”；反复无新证据会提示改策略，已确认交付且无待办时直接结束，普通聊天不增加规划或评审调用。

## QQ 行动与账号资料

| 工具 | 使用条件 |
|---|---|
| `list_owner_capabilities` / `request_owner_action` / `owner_action_status` | 当前真实主人查看、委派并查询已启用行动；普通成员调用返回受限 |
| `owner_action_notice` / `report_owner_result` | 将获准行动的真实进度/结果回传原请求范围，不把队列状态冒充平台成功 |
| `publish_qzone` / `comment_qzone` | 获准空间主体或主人行动可写；配额、冷却、好友/原帖复验和回执防重持续生效。评论按附图配置限制附件；文字评论的 `artifact_ids=[]`，读图产物无需附回。执行失败保留具体原因 |
| `find_friend` / `read_friend_feed` / `read_friend_posts` | 在获准公开行动范围按好友名单定位对象并读取真实动态；同名不猜，普通群观察不获得好友资料权限 |
| `observe_post_images` | 读取已获准好友原帖中的实际图片，最多9张；返回已读与未读数量，未读不猜 |
| `assess_qzone_post` | 记录实际评估版本及5–180分钟时效；纯图未读只能暂缓，不代替回执 |
| `set_nickname` / `set_avatar` / `set_group_card` | 当前已授权账号/群资料动作，不修改其他成员身份 |

好友动态在获准空间行动中读取实际原帖，主聊天通过既有主人行动入口请求；不能仅凭缓存标题或“没有检索到”断言好友未发布。空间任务不会自动导入群私原文。

部署者还可显式配置受限 MCP 扩展；其工具名和schema取决于本地许可清单，不属于所有安装默认具备的内置工具。扩展不能绕过当前来源、作用域及写入回执要求，见[配置参考](CONFIGURATION.md)。

## 独立 X 下载命令行

独立下载，依赖 Python 和 `httpx`：

```powershell
python -B -X utf8 scripts/download_twitter_media.py "https://x.com/i/status/900000000000000001"
python -B -X utf8 scripts/download_twitter_media.py "帖子链接" -o "D:/Downloads/X" --proxy http://127.0.0.1:7897
```

默认保存到 `data/twitter_media/帖子ID-随机串/`，含媒体和 `manifest.json`。图片orig网络/可恢复HTTP、不完整或超字节预算时仅降到large；预算、时限、校验不变。鉴权、429、非法URL/签名、取消不降档，视频在同一预算内最多试3种原生MP4，动图标kind=gif。清单保留来源/顺序/解析器/字节/SHA256和image_size/fallback_reason；quality_fallbacks及自动交付文字注明非原图。CLI先用公开嵌入，失败试FxTwitter，`--resolver`可指定syndication/fxtwitter，不读取浏览器登录态。

CLI视频默认100MiB/文件、图片8MiB、300MiB/次、180秒，可用`--max-file-mib`、`--max-total-mib`、`--timeout`调整，每URL最多3次尝试。**手动文件由用户管理，不自动淘汰**；失败/取消清理本次半成品，重复下载保留旧结果。机器人使用前述限制及受控缓存。

配置X会话后，X工具使用容器gallery-dl及一次twscrape备选；搜索与筛选规则见上文，交付沿用缓存、队列和QQ回执。会话、代理及更新见[WSL操作](../infra/wsl/README.md)，扩站见[开发合同](DEVELOPMENT.md#x爬虫采集合同)。
