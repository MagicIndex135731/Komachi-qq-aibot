# 开发与测试

用途：操作指南；读者：开发者；维护者：项目维护者。

## 环境

工程要求 Python 3.12 或更新版本，生产镜像基于 Ubuntu 24.04/Python 3.12。Agent SDK 与原生运行时均固定为 `0.1.5rc1`，不要只升级其中一个。开发机需要 Git；Windows 的生产入口还需要 WSL2/systemd、Docker/Compose。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest -q
python -m compileall -q app scripts
python -m pip check
```

Linux 对应使用 `python3.12 -m venv .venv` 和 `source .venv/bin/activate`。依赖安装需要联网；离线测试使用 fake provider，不应访问生产账号或调用付费模型。个别原生 Harness 测试依赖已安装的运行时。

## 测试目录

测试源码放 `tests/`，按模块镜像分类。默认 pytest 夹具和缓存统一 `data/test-work/`，每次运行生成独立临时目录，防止并行测试相互删除。手动指定仓库内 `--basetemp` 时也必须位于这里；仓库外独立临时目录可用于隔离回放。

```powershell
python -m pytest -q tests/agent tests/private_chat
python -m pytest -q --junitxml=data/test-work/full.xml
powershell -ExecutionPolicy Bypass -File scripts/clean_test_tmp.ps1
```

清理脚本默认只预览；确认没有仍在运行的测试后加 `-Force` 清理，先将必要报告移到私有 `data/` 工程目录。不要清理生产数据卷，不要在根目录创建 `.test-tmp-*`、复制依赖或留下私有测试聊天。

## 修改边界

- `app/adapters/` 解析平台数据并返回真实回执，不负责推理和长期记忆策略。
- `app/core/` 的业务规则尽量独立于 `.env` 和网络，使来源、时间、预算与检索可隔离验证。
- `app/storage/` 负责表/仓储/迁移，避免在路由器中创建 schema 或拼重复 SQL。
- `app/runtime/` / `*_main.py` 是依赖装配与进程入口；群记忆初始化不迁入私聊进程。
- `app/agent/` 向 Harness 暴露允许的工具，来源、权限和副作用仍由 Python 业务层掌握。

共享配置、工具 schema、数据库字段或跨层数据结构变更前，检索所有消费方并一起校验。保留群隔离、真实作者、canonical 来源关联、有限重试和 unknown receipt 状态。

## 验收层级

1. 先用合成账号/群号、临时数据库和 fake gateway 验证本次规则。
2. 按影响范围运行局部及直接消费方测试、compileall 与必要依赖检查；共享契约或广泛影响时运行完整 pytest。
3. 改部署时验证 Bash/Compose、构建快照和实际健康检查。
4. 真实模型回放与实际 QQ 动作分别记录；没有 QQ 回执不能声称平台提交成功。

模型评估可能收费；账号登录、空间评论/发布等会产生外部影响。不要把离线测试通过或旧测试数量当作当前真实链路结果。

## 网页资源成本回归

`python -B -X utf8 scripts/benchmark_agent_resource_context.py --output data/project-tools/resource-context-cost.json` 使用合成页面比较原16000字符与新6000字符默认回包、重复读取、跨轮短摘要稳定性和原文恢复，不调用上游模型。报告的文本token是估算，`actual_cached_tokens`保持未知；真实缓存收益须从运行usage核对。普通下载只回传句柄和资源角色，显式读图才将像素送入模型。提取器网络必须走既有公网校验和有界读取，不可直接启用库内下载、浏览器Cookie或用户配置。

## X爬虫采集合同

`x_posts.py`定义规范目标、原帖投影和快照，`x_crawler.py`使用gallery-dl主源及twscrape备选；`XCrawlerClient`通过固定Python子进程调用`scripts/x_crawler_worker.py`。两库随小町镜像安装，群私共用发现/核验/下载合同，不增加模型或宿主网关。未来网站适配应复用目标校验、投影、有限回退和既有下载器；QQ权限、队列及发送不进入站点解析器。

- X会话由用户授权后放入WSL私有目录（目录0700、JSON0600，仅auth_token/ct0），只读挂载至应用容器；不挂到QQ平台/监控容器、不进入镜像、模型、参数、管道或日志。子进程只继承必要PATH/语言与可信会话路径、代理配置，不继承模型密钥；不写Cookie库或开启遥测。人工登录profile独立保留，生产采集不操作浏览器。
- 只允许固定list/search/inspect和规范HTTPS目标。库请求限制为X/Twitter/twimg只读GET/HEAD/OPTIONS及列出的GraphQL查询；禁止写操作和任意命令/库动作。明确使用WSL日本代理，CDN字节通过无Cookie客户端走同一出口；不把认证头发送到媒体CDN。
- 每个应用进程同时最多一个采集；排队最多8秒并复验来源，子进程硬超时45秒，内部共35秒、每个库最多18次HTTP请求（合计最多36次）、单次8秒、响应8MiB，结果256KiB/24帖，解析树深度/节点有界。图库主源仅在解析、元数据、网络或不可用错误时尝试一次备选，共用截止时间；登录/挑战/限流/身份错误直接报告，不轮换账号或绕验证。同轮同一发现工具遇到认证/挑战/限流后锁止，换关键词/窗口/排序也不再请求；不将此锁止视为跨进程或持久冷却。
- 根帖ID、作者和来源必须一致，作者protected明确为false。引用/转帖不递归；只接纳根帖媒体，顺序/数量不一致明确缺失，不用预览图替代MP4。账号查询排除回复/转帖；列表无日期要求默认无下界；显式窗口才排除窗外项，异常未来日期排除，完整性和绝对最新性始终未证明。明确URL可检查旧帖。主题查询保留跨发布者，不自动限定本人。
- 主题搜索将主体/主题组、近N天、image/video类型及显式数字互动门槛编译为[站内高级搜索](https://help.x.com/en/using-x/advanced-xpro-features)。日期用UTC日历边界略宽召回，再按精确滚动窗口核验；类型、点赞/回复/转发门槛再核验，计数缺失不能当0或视为达标。latest按时间、top保留各路平台顺序；Top不等于互动数全站最高。主体词面命中优先，lexical_match标记词面证据，未命中不直接丢弃语义候选，也不能认定人物/主题已核实。
- media_types同时含image/video时分两路，每路最多max(12,limit)个候选，共用35秒及每库18次HTTP预算；根帖去重并为每类保留位置，摘要裁剪继续保留唯一类型。missing_media_types只表示候选类型缺口，不证明语义合格。关键词不足可topic_match=review保留主体和其他筛选，再按原帖正文核验主题；原用户主题不放宽。主体别名最多3个、主题词最多4个，每词40字符；schema与提供方共用上限。raw仅允许用户原样查询，不能自行改from，最多300字符；semantic拼接最多400，程序编译后最多600。worker输入上限8KiB以容纳最长多语言词组，仍有界拒绝超限。同轮缓存包含全部结构化条件；同义组去重，大小写/词序等价复用且不占查询次数，窗口/主题/排序/门槛不同仍重查。通常每组1至2词，不凑满4词；先筛12条已有候选，再按需补搜或批量下载。
- `x-posts-<内容哈希>:post:N`证据关联规范来源及投影；摘要省略媒体URL，完整投影留本请求证据。下载重新核验原帖、域、类型、数量并复用`TwitterMediaDownloader`临时目录、大小/格式/哈希、有限重试及失败清理；图片解码和视频ffprobe/实际观看另列证据。
- 当前来源授权、日期门、撤回、群私隔离、持久队列、DownloadedMediaCache和发送账本持续生效。配置会话的来源失败显式返回缺口，不静默改用旧嵌入结果。未配置会话保留公开单帖/账号路径，登录态主题搜索不可用。扩站需单独补合成边界与真实公开目标验收，代码存在不代表已支持。

部署与会话更新见[WSL操作](../infra/wsl/README.md)。扩站时沿用本节的解析、来源、预算和停止条件，并用合成数据分别验证发现、下载及发送回执。

## 小红书容器采集合同

`xhs_crawler_client.py`只调用固定`xhs-readonly`子进程；`infra/wsl/xhs-crawler/main.go`复用xiaohongshu-mcp 7797fd37的搜索、笔记详情和人工扫码动作，使用镜像内Google Chrome 155.0.8059.84。这是站点动作适配，不启动上游完整MCP服务，也不使用其自带指纹浏览器；没有发布、评论、点赞、任意命令或任意URL动作。Go仅在Docker构建阶段存在，Chrome与工具随小町镜像安装，宿主不安装运行依赖或采集服务。

- 模型入口只有`search_xhs_posts`及既有核验/下载工具。搜索词最多120字符，默认6条、上限12条；相关/最新、图文/视频为平台筛选，不套X的OR/from语法。同轮最多4次请求，同参数复用；认证、挑战、权限或限流后本轮发现锁止。未取得候选不证明平台没有内容。
- 搜索只投影标题、作者、笔记ID与待核验类型，封面不作为附件，日期保持未知。详情须与24位ID一致，只投影该笔记正文、UTC发布时间与有序附件；推荐、头像、评论不作正文媒体。可读性仅说明当前授权会话可访问，独立公开性未知，不套用X的protected=false。私密/仅自己或作者可见提示拒绝。
- 会话仅在专用Docker卷`xiaomachi-xhs-session`，仅群私应用挂载为`/workspace/data/xhs-crawler/session.json`（0600，目录0700）。扫码入口只供本机运维人员调用，不进入模型工具；QR最多等待240秒，成功原子保存会话。模型参数、stdout、日志、报告和镜像不接收Cookie值；worker仅继承PATH/语言/时区，不继承模型密钥或环境代理。小红书当前直连，独立于X的日本代理。
- 跨群私进程使用同一文件锁，每次只运行一个采集。stdin最多8KiB、stdout最多512KiB；采集内部80秒、客户端最多85秒且服从调用方更短截止时间。浏览器最多600个请求、180个站点API请求及32MiB接收数据；人工登录最多1200请求及5分钟总限。主文档或站点API的401/403/429、页面挑战/权限提示分类停止，无提取器/出口回退；超时或取消清理进程组，浏览器临时profile结束清理，会话保留。
- 内部JSON快照仅用于复用纯解析器，不当作下载的站点HTML或原文证据。详情后的CDN字节仍经既有无Cookie、公网DNS固定及逐跳校验的下载器。图片为站点提供的实际尺寸，不证明原始质量；视频只接受h264/实证EF4 AVC MP4，拒绝DRM，不以EF5或封面替代；最终ffprobe/格式/尺寸/容量检查持续生效。
- 原请求近期日期门覆盖小红书图片和视频；图集候选、标准URL及已核验短链别名绑定原帖日期，未知、旧及异常未来日期不得排队。来源、群私隔离、持久队列、缓存租约、续办和send_media_once复用现有链路，不新增持久任务schema。真实QQ收播与模型自然语言选工具另行记录，不以抓取成功代替。

## 媒体工具接入合同

新增下载、生成或耗时媒体工具时，先复用现有能力，按下列边界接入：

1. 工具目录及schema保持稳定，执行时按当前真实请求、账号、作用域及原始来源授权；群主动观察不能借子任务绕过联网和调用限额。
2. 确定性下载/绘图使用持久媒体队列，不额外启动聊天模型。下载工具提供auto/review交付选择，默认review兼容旧任务；auto仅限当前用户明确下载请求，持久绑定原作用域/来源，走既有发送账本直接交付，未知结果不重放。只有确需独立推理的多步资料研究使用只读模型子任务；回传只含有界结果、产物及证据索引。
   纯auto单项或全部接受的auto批次在原生工具结果保存后本地结束主回合，结果为交接待交付，不伪造QQ回执；不额外调用模型生成排队提示。部分批次、review及分析任务继续原流程。账号发现按会话配置使用爬虫或公开嵌入，沿用来源授权和受控只读请求；未指定日期时无发布下界；lookback_days仅为可取消的软检索窗口，最近未定天数可先试7天并说明覆盖。仅明确日期产生硬门，范围外或日期未知不能证明合格；模型改写目标不能放宽。公开嵌入的完整性/最新性保持未证明，空窗口只报告抓取缺口。
3. 机器人外部媒体统一进入DownloadedMediaCache。下载前预留容量、流式限制总字节与时限；原图/视频校验后注册有来源的产物。临时目录受控且可在失败、取消或中断后回收，不使用独立CLI永久输出目录作缓存。
4. 正在执行的文件用短租约保护，持久有效待回传结果由任务状态继续保护；任务结束后按TTL/容量淘汰，容量全部被占用时明确拒绝。不得删除生成作品或用户手动文件来腾空间。
5. 多图、多视频及混合媒体保留原顺序，按下述分包上限通过合并转发提交；单视频继续走专门发送参数，禁止传入任意本地路径。视频节点不得与文字/其他视频混合，说明文字单独节点；含视频的转发也须使用有界上传时限。真实账号署名，当前守卫在派发前复验，未知回执不自动重放。
6. 批量操作通过通用queue_media_batch组合现有下载合同；活动容量与整项任务规模分开，pending复用持久来源/快照、取消和去重。原请求有效的内部回传可续办；普通定时/自主巡检不能借此联网。
7. RequestTaskControl绑定原请求，分开内容主体、发布者、站点、日期、数量和类型。未提日期或被否定/引用的窗口不产生硬下界；lookback_days允许null且0无效，只改变检索策略。明确近N天/年份、本人账号、最终来源站点和数量从原话保留，模型目标不得放宽，也不能把偏好升格硬条件。“一些”保守最低2份；明确大数量不被单工具批次上限截小。图和视频都要时分别验收类型。主题媒体依据原帖正文/日期/类型；selected评审或明确交付选择用于收尾准入，歧义时才少量看静态图片，不预览视频/动图。候选、文件READY、语义选择、发送回执、请求完成分开。合格子集可partial先发；尚有候选、未发成果或pending时保持继续状态，不能假称后台已启动。
8. send_media_once在原账号、原会话和原请求source_id内逐逻辑媒体认领，并保留旧整批效果围栏。稳定来源/序号识别同一媒体的不同清晰度，字节摘要识别相同文件；后续A+B仅发新增B。成功复用真实回执，未知不重放，明确失败最多修正一次。旧整批记录无法证明子集时拒绝推测重发。授权、来源依赖、取消和发送配额仍由原边界复验；不得恢复历史句柄权限。私聊完整目标及真实回执确认后才记录media_goal_completed；partial、未知和纯文字不算完成。
9. 覆盖群/私聊、来源撤回、跨作用域产物、顺序、失败取消、容量与待回传保护、实际发送及未知回执。轮询与后台回传的测试必须等待两条路径结束再统计真实网关调用，不能在首条媒体送达后立即停服务。更新[工具清单](TOOLS.md)、配置/架构的对应权威段落；README只介绍能力和入口。

任务纠错优先复用原模型回合。schema失败返回有限字段名/约束及handler_executed=false，不回显任意参数值；模型先改参数，不能误报上游不可用。联网否定词不跨标点；明确搜索/下载与“不逐图看/不看视频”的省token要求可并存，明确不要联网仍阻断。连续无进展时换方法；短复核最多一次、512输出token、共享原回合及每日预算。媒体发现连续两次无进展时复核canonical_request，防止主体当作者、排除图片扩大为排除造型、期望数变硬要求。主题词由模型提供、程序组合，召回不足可改别名或review模式，不硬编码人物。明确时间/类型/互动门槛不可放宽；仅未定天数且不足可说明后扩大。方法经验仅接纳真实回执、7天有效并匹配请求者/作用域与版本，和任务状态、V3事实记忆分开。实测记录目标完成、缺口、重复调用、实际usage/未缓存输入及限制。

## 跨站媒体预算与尽力交付

此共享合同由RequestTaskControl、RequestBudget、media_delivery和现有下载工具实现；站点适配只提供根帖证据和资源版本。普通单项下载、校验、注册失败不回滚已成功兄弟项；逐项记录ready/失败、顺序、逻辑身份、句柄、字节和实际质量。下载成功但部分失败时仍返回可用句柄；后台长结果压缩正文/来源描述，保留句柄与失败清单，不替换为空错误。撤销/取消不授予发送权。昵称不证明唯一发布者；显式账号限制需要handle或平台author_id证据，小红书唯一作者限制尚未实站验收。

同一原请求前台、后台和回传共用持久预算：模型准入24、估算token 256000、工具64、发现8、实际响应/媒体字节384MiB、保守网络预留768MiB、传输请求96、写入8、总时长600秒。已持久化的旧请求保留原额度。Gemini WebSearch与短复核也计入模型预算；准入/估算与实际usage分别记录，失败用量未知不记作零费用。浏览器及X子进程元数据每次先预留32MiB上界；普通HTTP逐块计实际接收，重试/降档不重开流量与截止时间。子进程HTTP请求仍有站点内上限，总工具/流量/时限另行约束，不把预留数称作实测流量。

前台在现有时限内预留最多20秒和一个发送机会；收尾上限还受原请求600秒及原guard限制，模型预算耗尽不撤销已有成果。零媒体且没有待处理任务时，若模型对已有可下载候选全部排除或未选中，在终止文字发送前或回合结束时本地兜底一次：最多12个来源/下载，每次最多6张图片，复用原媒体队列auto交付，不再调用模型或新搜索。候选按每批最多3项排队；上一批结算后仍缺数量或类型才执行下一批，按真实送达及媒体身份去重计数，够数且类型齐全便跳过剩余下载，未知回执或取消停止续补。中途候选下载失败不逐项发送失败提示，保留已成功兄弟项。必要的原帖核验/图册提取单次最多12秒并服从原剩余时限；一次性计划按原请求持久保存。明确日期、站点、发布者、媒体类型和原图要求继续核验；X整帖类型混合且违背单类型要求时跳过。说明标注“网页候选直接取回，内容尚未逐项核实”，不宣称语义合格或目标完成。其余确定性finalizer只发送当前请求已选定、有效READY且未送达的一个有界包；来源、作用域、授权及真实发送账本复验，撤销、取消、过期、发送中或未知回执均不重放。后台作业completed只表示该作业结算，不表示整个用户目标完成。

同一视频最多尝试3种兼容原生版本，保留分辨率/码率/时长/声明及估算大小；声明超限先跳过，未知长度按实收流量拦截后可在同一预算尝试低档。视频降档单独记录video_quality_fallbacks，不读取图片image_size；无可用MP4时保留格式、时长或估算大小拒绝计数。不截短、不以封面替代、不默认转码。图片传输与注册统一8MiB，必须原图时不降档；小红书默认服务图不具有原始上传质量证明。小媒体按顺序规划20项/32MiB包，超过32MiB的有效视频独占一包；这属于应用规划，底层混合发送硬上限仍为128MiB、单视频128MiB/20分钟。剩余成果按有限缓存租约/TTL保留；没有新授权不复活过期交付。
